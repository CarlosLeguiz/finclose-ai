# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records for the FinClose AI project.

An ADR captures a single architectural or technical decision: the context that led to it, the decision itself, and its consequences. ADRs are immutable — if a decision is reversed, a new ADR is created that supersedes the old one.

## Conventions

- **Filename format:** `NNNN-title-in-kebab-case.md`
- **Status values:** `Proposed`, `Accepted`, `Superseded`, `Deprecated`
- **Sections:** Context, Decision, Rationale, Consequences, Revisit when
